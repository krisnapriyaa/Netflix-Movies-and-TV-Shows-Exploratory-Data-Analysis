# Netflix Movies and TV Shows – Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python, Pandas, Matplotlib, and Seaborn.

The objective is to identify patterns, trends, distributions, and missing values in Netflix's content library through statistical analysis and data visualization.

## Dataset
- **Source:** Kaggle
- **Dataset:** Netflix Movies and TV Shows
- **Records:** 8,807
- **Columns:** 12

[Download Dataset – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## Key Findings
- Movies represent the majority of Netflix titles.
- The United States contributes the highest number of titles.
- TV-MA is the most common content rating.
- 2018 has the highest number of titles by release year.
- The director column contains the most missing values.
